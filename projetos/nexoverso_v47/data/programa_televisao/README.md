# Programa de televisão

Os conteúdos desta categoria ficam separados por **tema principal** para facilitar a manutenção manual.

- `motorhome/`
- `automoveis/`
- `motocicletas/`
- `mecanica/`

O campo `generos` continua dentro de cada conteúdo. A pasta organiza os arquivos; ela não substitui os gêneros usados pelo sistema.
