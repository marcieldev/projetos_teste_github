# Publicação no GitHub Pages

1. Crie um repositório para esta central.
2. Envie todo o conteúdo desta pasta para a raiz do repositório.
3. Em **Settings → Pages**, selecione a branch principal e a pasta `/ (root)`.
4. Acesse a URL gerada pelo GitHub Pages.
5. A central carregará `data/projetos.json` e exibirá os projetos.

Cada projeto deve ficar em `projetos/NOME_DO_PROJETO/` e ter seu próprio `index.html`.
